# Warning Label for Humans: One Line, Big Laugh

Entry for the make.fun bounty
`u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85`.

`main.py` writes one single-line safety warning label — the label that
should come printed on every human being — to `/output/entry.txt`.
The label is at most 160 characters, funny first and plausible second:
it reads like a real printed product label, names a behaviour every
human recognises, and lands its punchline in the last few words.

Run it with `python3 main.py` (no dependencies, no network).
